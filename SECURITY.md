# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues or pull requests.

Use GitHub's private vulnerability reporting feature on the Security tab of this repository. Include the affected version, reproduction steps, impact, and any suggested mitigation. The maintainer will acknowledge the report and coordinate remediation and disclosure through the private advisory.

Never include TestRail URLs, usernames, API keys, access tokens, customer data, or other secrets in a report, test fixture, commit, or log. Revoke and rotate any credential that may have been exposed.

## Supported versions

The latest commit on `main` is supported. Pin deployments to a reviewed commit SHA when reproducibility is required.
